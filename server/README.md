# WasteWise AI — Backend Server

The backend REST API server for WasteWise AI, built with **Node.js**, **Express**, **MongoDB Atlas**, and **Groq AI SDK**.

For full project documentation, architecture, and setup instructions, please see the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Seed demo data
npm run seed

# Start development server
npm run dev
```
