# WasteWise AI — Frontend Client

The frontend client for WasteWise AI, built with **React 19**, **Vite**, and **Tailwind CSS**.

For full project documentation, architecture, and setup instructions, please see the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
